## 发布与更新

发布脚本只在本地生成 ZIP、appcast.xml、SHA256SUMS，不要求 Apple 证书、公证或 GitHub Secrets。已删除自动发布工作流及 CI 凭据脚本，保留只读权限的测试与构建 CI。上传和发布由所有者另行决定。

每日检查、手动检查、跳过版本、稍后提醒和用户选择安装保持不变。更新包和更新说明仍强制验签。VERSION 是唯一版本来源，不自动升版本。本机旧 1.x 开发版需手动迁移一次到 v0.1.0。
