# LumaRing v0.1.0 本地验证

2026-09-07，macOS 26.2 / Apple M4。版本由所有者指定为 v0.1.0；仅本地提交，不推送、不创建远端仓库、不发布 Release，也未替换正在使用的已安装开发版。

## 版本控制

- VERSION 是唯一版本来源；构建派生显示版本、bundle version 和安装包名称，不修改该文件。
- AGENTS.md 明确要求：只有所有者指定新版本时才更改版本，不自动加 build number、创建标签或发布。
- 之前的 1.x 编号是本机开发记录，不是公开发行版本。旧本机开发版需手动迁移一次到 v0.1.0，后续公开版本按数字版本顺序升级。

## 已验证

- 48 项 Swift 测试：46 通过、2 项依赖真实测试窗口的检查跳过、0 失败。原有应用/窗口/标签切换回归测试通过；新增更新配置与数字版本比较测试通过。
- 9 项发布工具测试全部通过：版本源保持不变、标签不匹配拒绝、重复版本拒绝、错误仓库和归档地址拒绝、签名与篡改检测、默认检查策略、发行构建不能回退到 ad-hoc。
- 真正调用 Sparkle 2.9.6 generate_appcast，使用可丢弃测试密钥为实际开发归档生成签名 feed，再以公钥校验归档和 feed，均通过。测试不启动、不安装应用，临时副本自动清理。
- Universal 开发构建（arm64 / x86_64）、严格签名检查、framework 符号链接及 helper 完整性检查通过。归档的两个版本字段均为 0.1.0。
- 本地构建的 diagnostics 可正常运行，确认动态 framework 可加载。
- 两个 GitHub Actions YAML 可解析，shell 脚本语法检查通过，git diff --check 无错误。

## 更新行为与发布流程

- Sparkle 执行每日检查、提醒、跳过版本的持久化、签名验证、安装和重启。LumaRing 没有自行实现替换应用的更新器。
- 默认开启检查，但禁止自动安装；不启用系统画像上传。用户可以手动检查、忽略当前版本或稍后提醒。
- 更新包在解压前验证签名，feed 和嵌入更新说明要求签名，未签名的 feed 不降级放行。
- GitHub 工作流仅由版本标签触发，检查版本一致性后测试、签名、公证、装订、校验，最终创建草稿，正式发布由所有者操作。
- 签名公钥已保存到配置中；正式私钥生成在本机钥匙串，未导出、未提交。实际生产签名工具本次未获钥匙串读取许可，正式签名仍需允许该工具读取私钥或配置 CI Secret。
