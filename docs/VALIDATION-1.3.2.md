# LumaRing 1.3.2

针对“点击网易云音乐后轮盘关闭，但应用窗口未出现”的反馈，替换只调用 NSRunningApplication.activate 的流程。应用与窗口切换统一通过 NSWorkspace.openApplication 唤起现有应用；具体窗口在唤起后恢复和置前。单窗口应用不因缺少 AXRaise 实现而把成功的应用唤起判为失败。

2026-09-07：Universal Release 编译成功。32 项测试中 30 项通过、2 项真实窗口集成测试按默认规则跳过、0 失败。新增覆盖重用现有进程、打开失败、目标进程已退出。此次未启动测试窗口。

安装位置为 ~/Applications/LumaRing.app。用户已在安装版通过轮盘点击网易云音乐，确认“可以正常切过去了”。更新后已在系统设置重新关联两项原有权限，重启后安装版 UI 确认两项均已授权。
