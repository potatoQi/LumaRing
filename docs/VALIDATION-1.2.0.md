## 安装版检查

- Universal Release 编译成功，包含 arm64 / x86_64，安装版通过严格签名校验。
- 设置页显示版本 1.2.0，按住选择和名称排序已开启，分区为 8。
- 名称显示和减少动画开关已移除；权限页没有资源使用区块。
- 新图标在实际应用设置标题及系统文件图标 API 中显示正确。图标资源为 `LumaRingIcon-1.2.icns`，不再依赖旧文件名缓存。
- 白 / 黑、6 / 8 / 12 / 16 / 24 图标排版和大预览渲染已检查。

## 仍需用户完成的系统步骤

应用更新签名后需刷新已有辅助功能记录，系统触控 ID / 密码弹窗正在等待用户本人验证。辅助功能的对象和范围未增加。

为安装版新增屏幕录制权限的确认问题也已发出；收到允许前不修改此权限。没有该权限时，预览卡片只显示标题与状态提示。

因此，最终安装版的完整“悬停 → 邻近图片预览 → 松开切换”操作还需要上述系统步骤完成后继续实测。没有将测试进程的权限或测试通过当作安装版已经授权。

## 验证范围

未全面覆盖 Intel、多显示器实机、所有系统版本、跨 Space / 全屏组合及长期运行。真实物理键盘的按住 / 松开系统事件仍需用户实测；自动化测试验证的是这些事件到达后对鼠标目标的选择逻辑。

1.2.0 删除了玻璃合成，没有增加周期轮询或持续录屏；仍保留查询和预览的并发、超时和缓存边界。资源测试不能代表绝对零耗电。

本机为 ad-hoc 签名，无 Apple 公证。旧版本记录见同目录的版本化验证文件。
