# LumaRing 1.0.0 验证记录

日期：2026-09-07。环境：macOS 26.2，Apple M4，24 GB 内存，Swift 6.3.3 / macOS SDK 26.5。

## 构建与交付

- Release 构建成功，包含 arm64 和 x86_64；部署下限 macOS 14。
- 安装于 `~/Applications/LumaRing.app`。安装版与交付版可执行文件逐字节一致。
- `codesign --verify --deep --strict` 对安装版和交付版均通过。
- 本地 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证；适合本机使用。更新后可能需重新添加辅助功能授权。
- 辅助功能已由用户授权，并在最终安装版确认“窗口切换已就绪”。预览和登录启动仍默认关闭。

## 资源测量

轮盘与设置窗口均收起、预览关闭，使用只读 `ps` 和 `vmmap`。采样过程未修改电源设置。

| 指标 | 结果与口径 |
| --- | --- |
| 最终版后台 20.224 秒 | 累计 CPU 时间增量在 `ps` 的 0.01 秒精度下为 0.00 秒；不能据此声称绝对零耗电 |
| 前一版本后台 20.238 秒 | CPU 时间增加 0.04 秒，约为单个核心的 0.198% |
| 最终版 physical footprint | 56.9 MB，历史峰值 155.1 MB |
| 最终版 RSS | 134.5 MiB，采样期间无增长；RSS 与 physical footprint 是不同统计口径 |
| 轮盘显示调度耗时 | 4 次日志为 8.53、15.29、44.24、47.75 ms；包含首次与重复调用，仅衡量函数开始到提交显示，不等于从按键到屏幕呈现或窗口列表加载完毕的延时 |

这是一台机器上的短时采样，不是长期能耗、无泄漏或所有机器流畅度的保证。默认显现动画约 90 ms，可在设置中减少动画。

结构上没有空闲窗口轮询、持续录屏或周期动画。窗口查询串行且有超时、取消和过期结果保护；预览最多一项进行中、仅保留最新待处理项，收起时清理缓存。实际窗口由目标应用提供，拒绝或响应慢时会显示提示。

## 尚未覆盖的环境

- 未实机覆盖 Intel、macOS 14/15、多显示器组合、所有全屏及跨 Space 场景。
- 登录启动已实现，未更改用户登录项进行注销 / 重启实测。
- 安装版可选预览尚未申请屏幕录制权限，因此保持标题模式。
- 未进行长期运行、压力循环和外部应用全量兼容性测试。跨桌面及目标窗口置前受 macOS 和目标应用限制。

## 复验

```bash
bash scripts/build-fixture.sh
open "work/LumaRing Test Windows.app"
LUMARING_LIVE_TESTS=1 swift test
bash scripts/build.sh
codesign --verify --deep --strict dist/LumaRing.app
# 将 PID 替换为安装版的实际进程号；轮盘收起后运行
python3 scripts/measure-idle.py PID --seconds 20
vmmap -summary PID
```

需最小化一个测试窗口后才能再次验证最小化属性；重新启动测试 App 会恢复初始测试条件。
