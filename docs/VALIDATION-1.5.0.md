# LumaRing 1.5.0 验证记录

2026-09-07，macOS 26.2 / Apple M4。

## 功能

- 默认预览 840 × 630 pt，保留可调尺寸与屏幕边界适配。旧默认 640 自动迁移，其他已自定义尺寸保留。
- “应用过滤”改名“应用管理”，各应用独立选择窗口或标签页，默认窗口；未适配应用禁用且去色。
- 适配稳定版 Microsoft Edge / Google Chrome，直接使用本机 Apple Events，无浏览器扩展。后台标签悬停展示标题和网址，窗口保留图片预览。
- 标签页顺序改变或移动到其他窗口后，重新解析稳定 ID；关闭目标时不误选别的标签。二级圆弧继续按每页四项显示并支持鼠标翻页。
- 新增浏览器自动化权限入口及状态提示，未连接时不会在悬停中反复弹授权。

## 自动化验证

45 项测试，43 项通过、2 项真实测试窗口集成测试跳过、0 失败。新增 11 项浏览器测试覆盖：默认值与持久化、未知适配器/未来配置回退、Unicode 与网址保真、原生 all 序数描述符、标签重排、移动与最小化恢复、关闭与并发窗口变动、取消/超时、权限拒绝、512 项限制、单窗口多标签展开与分页。

Universal Release（arm64 / x86_64）构建通过，严格签名验证通过。签名包含 Apple Events 自动化 entitlement 和明确的用途说明。

## 实机验证

- 安装 UI 确认预览为 840 × 630，默认 Option + Tab、80 ms、12 分区、按住选择关闭，原有登录启动开启未改变。
- Chrome 首次出现在应用管理时默认“窗口”，其他未适配应用选择器禁用；切为标签页后显示独立连接入口。
- Edge 与 Chrome 的实际连接均通过，分别读到当时的 1 和 3 个标签页。实测发现 Chromium 要求 typeAbsoluteOrdinal，修正后加入回归测试。
- 系统本人验证后恢复原有辅助功能和录屏权限；安装版两项状态均已授权，ScreenCaptureKit 实际检测通过。
- 真实快捷键/鼠标切换结果待用户反馈。电脑操作工具无法触发全局 Carbon 快捷键。

本次未启动 LumaRing Test Windows 测试应用。临时 Chrome 窗口用于标签验证，收尾时退出 Chrome；Edge 与 Chrome 的验证用模式恢复为默认窗口。浏览器内容未写入测试日志。

最终安装版静置采样 20.228 秒，ps 的 0.01 秒时间分辨率下 CPU 时间增量为 0.00 秒；RSS 144.69 MiB（设置窗口仍打开）。这不代表绝对零能耗。安装版与打包版可执行文件 SHA-256 一致。Chrome 退出已通过界面工具的运行状态列表确认。
