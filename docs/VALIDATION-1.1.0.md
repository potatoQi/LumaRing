# LumaRing 1.1.0 验证记录

2026-09-07，macOS 26.2，Apple M4，24 GB 内存；Xcode 26 / Swift 6.3.3。

## 本次变更

- 默认可见圆盘直径从 630 pt 缩到 236 pt；480 pt 透明面板用于容纳按需展开的圆弧，并非一直显示的大背景。
- 浅色圆角图标，仅保留淡蓝圆环和一段蓝色圆弧。
- 默认只显示 App 图标，去除扇形格子、标题栏、说明脚注和完整窗口外圈。
- macOS 26 使用 NSGlassEffectView 透明玻璃；macOS 14/15 使用 NSVisualEffectView 毛玻璃。没有以截图伪造模糊，也没有新增录屏要求。
- 悬停 180 ms 后读取选中的 App，只有多个符合过滤条件的窗口才展开局部圆弧。每页最多 4 项。
- 圆弧跟随所选 App 方位。穿过间隙保留选择，离开后 200 ms 收起；分页控件保持可达。
- 单窗口不展开，已读取的单窗口可以通过点击 App 或 Return 直接切换、恢复。
- 140 ms / 5 pt 圆弧淡入过渡，遵循减少动态效果设置。保留键盘、搜索、分页和可选预览。

`LUMARING_LIVE_TESTS=1 LUMARING_SNAPSHOT_DIR="$PWD/work/compact-snapshots" swift test`

**18 项测试通过，0 失败，0 跳过**，运行约 0.99 秒，不含编译。

- 7 项几何 / 请求状态测试，新增八个 App 方位的圆弧路径与命中一致性、圆角端点、反方向不命中、面板边界。
- 9 项交互 / 绘制测试，包括悬停延时、桥接间隙、离开收起、单窗口不展开与直接激活、四窗口分页、旧结果拒绝、录制快捷键、资源清理及绘图快照。
- 2 项真实窗口集成测试：独立测试 App 的 10 个窗口及最小化属性，ScreenCaptureKit 单张预览。这些测试使用测试进程已有权限，并不代表新安装签名自动获得权限。

已用安装版检查圆盘默认 236 pt、应用名称默认隐藏、实际原生玻璃画面及设置页面。未用静态图片冒充实际玻璃效果。

## 构建与资源

- Universal Release 构建通过，包含 arm64 / x86_64；Intel 未实机验证。
- 安装路径 `~/Applications/LumaRing.app`，源码 `~/Projects/LumaRing`。
- 安装版通过 `codesign --verify --deep --strict`；本地 ad-hoc 签名，没有 Apple 公证。
- 轮盘关闭后，20.231 秒内累计 CPU 时间在 ps 的 0.01 秒精度下无可分辨增长；不能解读为绝对零能耗。
- physical footprint 39.4 MB，历史峰值 100.1 MB；RSS 127.25 MiB，采样期间无增长。两种内存口径不能直接比较。
- 没有新增周期任务；玻璃由系统合成，仅在显示时参与渲染。
