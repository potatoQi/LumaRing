# LumaRing 1.4.0 验证记录

2026-09-07，macOS 26.2 / Apple M4。

- 二级圆弧改为直边扇环，去掉半圆端帽；主盘与圆弧背景使用单条连续外轮廓。自动化覆盖两到四窗口、多个方向、整个弧宽上的连接与端点外命中排除。
- 新增“通用 → 轮盘 → 预览大小”，默认 640 × 480 pt，可调 400 × 300 至 960 × 720 pt；邻近空间不足时按比例缩小。截图跟随实际卡片大小与屏幕倍率，最高 1920 × 1440 像素，仍为按需单帧。
- 默认 Option + Tab，安装版 UI 确认，无快捷键注册错误；保留用户自定义组合键。
- 34 项测试中 32 项通过、2 项需要实际测试窗口的集成测试跳过、0 失败。未启动测试窗口。检查了白黑外观、2 / 4 窗口以及 6 / 8 / 12 / 16 / 24 应用的渲染图。
- Universal Release 编译成功，安装版严格签名校验通过。安装版预览滑块实际从 640 调到 680，标签对应 680 × 510，随后恢复默认值。
- 标签页切换仅调研可行性，未实现。Chrome 扩展和 VS Code 扩展分别提供相关接口，需要按应用适配。

原有系统权限已通过 macOS 本人验证和重新添加流程恢复。重启后，安装版显示辅助功能与窗口预览均已授权，点击“检测预览权限”返回“窗口预览权限正常”。再次确认默认快捷键为 Option + Tab、预览为 640 × 480 pt。本地 ad-hoc 构建更新可能再次要求刷新授权。
