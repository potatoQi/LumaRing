# LumaRing v0.1.7

- Navigate the apps, app actions and favorites rings with Tab or Shift + Tab. Hold to continue moving and release to stop; Return activates the selection.
- Press the backtick/tilde key (left of 1) to enter the selected app's secondary ring; press again to return. Keyboard selection also shows window previews.
- Reduce repeated accessibility work, skip redundant queued window counts and release temporary resources sooner. Preserve input focus when using the app actions ring.
- Simplify the English and Chinese usage guides into common controls, keyboard navigation and window/app management.

Requires macOS 14 or later; supports Apple Silicon and Intel. Open the DMG and drag LumaRing to Applications.

---

- 在全局轮盘、应用内轮盘和常用应用外圈中，按 Tab / Shift + Tab 顺时针 / 逆时针选择；长按连续移动，松开停止，回车进入选中目标或执行操作。
- 按数字 1 左边的反引号 / 波浪号键进入当前应用的二级轮盘，再按一次返回；键盘选择窗口时也会显示预览。
- 减少重复的无障碍控件构建，跳过排队中的重复窗口计数，及时释放临时资源；应用内轮盘的键盘操作保留原输入焦点。
- 精简中英文使用指南，按常用操作、键盘选择、窗口与应用管理分类。

需要 macOS 14 或更高版本，支持 Apple Silicon 和 Intel。打开 DMG，将 LumaRing 拖到 Applications 即可安装。
