# LumaRing v0.1.0

First public release. Requires macOS 14 or later; supports Apple Silicon and Intel.

- Switch apps with Option + Tab and the mouse.
- Hover to reveal windows or Chrome / Edge tabs in the outer ring.
- See window or tab counts on app icons, with badges for multiple items.
- Preview windows before switching; customize ring size and items per page.
- English and Simplified Chinese interfaces, with light / dark appearance following the system.
- Signed updates through Sparkle, with manual checks and optional daily checks.

**Install:** download [LumaRing-0.1.0-macOS.dmg](https://github.com/potatoQi/LumaRing/releases/download/v0.1.0/LumaRing-0.1.0-macOS.dmg), open it, and drag LumaRing to Applications. If macOS blocks the first launch, allow it in System Settings → Privacy & Security. This release is self-signed and is not Apple-notarized.

Grant Accessibility access for switching, Screen Recording access for window previews, and browser Automation access for tabs. Tab previews show titles and URLs; image previews are for windows. The ZIP is used by Sparkle for updates.
