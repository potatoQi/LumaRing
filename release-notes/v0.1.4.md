# LumaRing v0.1.4

- Open favorites by holding Option in either ring mode. Left-Option hold recognition takes 150 ms and remains distinct from double-tap mode switching.
- Add per-app shortcut actions. Configure and reorder named shortcuts in Settings → Actions; double-tap left Option with the ring open to switch modes. Each app remembers its last mode across restarts. The action ring does not take input focus. It verifies the original window and, when available at invocation, its focused control; apps exposing only window focus use window-level verification.
- Preserve custom window and tab names and colors when a query temporarily omits an item, including during sleep/wake. Unavailable application-process information no longer triggers record deletion. Records remain scoped to the target application's current process and are cleaned up after that process ends; closing an individual window or tab does not immediately remove its record.
- Choose System, Light or Dark appearance in Settings.
- Close LumaRing Settings with Command + W or the enabled three-finger pinch gesture.
- Add unified local application logs, capped at 10 MB with automatic rotation. Disable logging, clear logs or open their folder in Settings → General → Local Logs.

Requires macOS 14 or later; supports Apple Silicon and Intel. Open the DMG and drag LumaRing to Applications.

- 两种轮盘模式均支持按住 Option 打开常用应用。左 Option 长按判定缩短为 150 毫秒，与双击切换模式分开。
- 新增按应用配置的快捷操作。在设置 → 快捷操作中录入快捷键并手动排序；轮盘打开时，双击左 Option 切换模式，每个应用独立记忆上次的模式，重启后仍保留。操作轮盘不抢输入焦点，校验原窗口以及呼出时可获取的输入控件；仅提供窗口信息的应用使用窗口级校验。
- 修复窗口或标签页暂时漏读时，自定义名称和颜色被误删的问题，包括休眠恢复期间的漏读；应用进程信息暂时不可用时，也不再误删记录。记录绑定目标应用当前进程，进程结束后清理；单独关闭窗口或标签页不会立即删除对应记录。
- 设置中可选择跟随系统、浅色或深色外观。
- 支持通过 Command + W 或已开启的三指捏合手势关闭 LumaRing 设置窗口。
- 新增统一的本地运行日志，总量限制为 10 MB，自动清理最旧记录。在设置 → 通用 → 本地日志中可关闭记录、清理日志或打开日志文件夹。

需要 macOS 14 或更高版本，支持 Apple Silicon 和 Intel。打开 DMG，将 LumaRing 拖到 Applications 即可安装。
