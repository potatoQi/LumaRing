**一个小圆盘，切换 macOS 应用、窗口与浏览器标签页。**

按下 **Option + Tab**，移动鼠标，点击切换。悬停应用，在旁边的圆弧中展开窗口或浏览器标签页。

需要 **macOS 14 或更高版本**，支持 Apple Silicon 和 Intel。

## 开始使用

1. 从 [Releases](https://github.com/potatoQi/LumaRing/releases) 下载并打开 **DMG**，将 **LumaRing.app** 拖到旁边的 **Applications（应用程序）**。
2. 打开 LumaRing，在设置中授予**辅助功能**权限。
3. 按 **Option + Tab**，或点击菜单栏图标，呼出圆盘。
4. 鼠标移向应用，展开它的窗口；点击应用或具体窗口即可切换。

再次按快捷键或点击圆盘外即可关闭。首次打开若被 macOS 拦截，可前往**系统设置 → 隐私与安全性**允许运行。
