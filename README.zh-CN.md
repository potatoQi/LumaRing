**一个小圆盘，切换 macOS 应用、窗口与标签页，执行应用内快捷操作。**

安装包仅约 **2.9 MB**，原生 Swift 构建，轻巧高效，切换流畅。

需要 **macOS 14 或更高版本**，支持 Apple Silicon 和 Intel。

## 开始使用

1. 使用 Homebrew 安装：`brew install --cask potatoQi/tap/lumaring`。也可从 [Releases](https://github.com/potatoQi/LumaRing/releases) 下载并打开 **DMG**，将 **LumaRing.app** 拖到旁边的 **Applications（应用程序）**。
2. 打开 LumaRing，点击菜单栏图标打开设置，授予**辅助功能**权限。
3. 按 **Option + Tab** 或三指、四指轻点触控板（在设置中选择），呼出轮盘。
4. 鼠标悬停应用，展开二级轮盘；点击应用、窗口或标签页即可切换。
5. 在**设置 → 快捷操作**中配置应用内快捷键；轮盘打开时，双击**左 Option**切换模式，也可在**设置 → 通用 → 唤起**中设置直接呼出的快捷键。

再次按快捷键或点击圆盘外即可关闭。首次打开若被 macOS 拦截，可前往**系统设置 → 隐私与安全性**允许运行。

## 核心功能

- 自定义应用内快捷操作与排列顺序，每个应用独立记忆轮盘模式。
- 一级轮盘切换应用，二级轮盘切换窗口或标签页。
- 悬停窗口即可预览。
- 两种模式下均可按住 **Option** 打开常用应用；双击全局轮盘中心可保持展开。
- 右键新建窗口、切换二级轮盘模式，或修改名称和颜色。
- 三指缩小以最小化当前窗口（需在设置中开启）。
- 点击 **×** 关闭二级轮盘中的窗口或标签页，拖出一级轮盘应用图标即可退出应用。
- 外观支持跟随系统、浅色或深色。
