**一个小圆盘，切换 macOS 应用、窗口与标签页，执行应用内快捷操作。**

安装包仅约 **2.9 MB**，原生 Swift 构建，轻巧高效，切换流畅。

## 安装

需要 **macOS 14 或更高版本**，支持 Apple Silicon 和 Intel。

1. **Homebrew**

   ```sh
   brew install --cask potatoQi/tap/lumaring
   ```

2. **[GitHub Releases](https://github.com/potatoQi/LumaRing/releases)**
